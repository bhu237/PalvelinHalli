## Demoni – Apache ja Nginx

### Tiivistelmät

#### Apache Ansiblella (package-file-service)

- Daemonit asennetaan mallilla: package → file → service  
- Ensin asennetaan ohjelma, sitten muokataan konfiguraatio, lopuksi käynnistetään palvelu  
- Muutokset tulevat voimaan vasta restartin jälkeen  

Oma huomio: miksi palvelua ei restartata joka ajolla?
---> Huomioon vastaus: _RIKKOISI IDEMPOTENSSIN, SIIS EI HYVÄ_

#### Handlers

- Handler suoritetaan vain jos task tekee muutoksen  
- Käytetään palveluiden restarttiin  
- Parantaa idempotenssia  

Oma huomio: estää turhat restartit

#### Notifying handlers

- Task käyttää `notify` kutsuakseen handlerin  
- Handler suoritetaan playbookin lopussa  
- Useampi task voi kutsua samaa handleria  

#### ansible-doc service

- Hallitaan palveluita (daemonit)  
- `state`: started, stopped, restarted  
- `enabled`: käynnistyy bootissa  


## Apassi

Asensin Apache2 käsin:

```bash
sudo apt-get update
sudo apt-get install apache2
sudo systemctl enable --now apache2
````


Testasin:

````
curl http://localhost
````

Loin oman sivun käyttäjänä:

````
mkdir -p ~/publicsite
micro ~/publicsite/index.html
````
Annoin oikeudet:
````
chmod ugo+x ~
chmod ugo+x ~/publicsite
chmod ugo+r ~/publicsite/index.html
````
Kopioin sivun Apachelle:

````
sudo cp ~/publicsite/index.html /var/www/html/index.html
````
Testasin uudelleen ja sivu näkyi selaimessa.

## Moottorix

Ennen asennusta pysäytin Apachen:

````
sudo systemctl stop apache2
````
Asensin Nginxin:

````
sudo apt-get install nginx
sudo systemctl enable --now nginx
````

Testasin:

````
curl http://localhost
````
_Oh my days! Sivuni toimii apache2 sijasta nginxillä_

Loin oman sivun:

````
micro ~/publicsite/index.html
````
Kopioin sen:
````
sudo cp ~/publicsite/index.html /var/www/html/index.html
````
Sivu näkyi onnistuneesti.

## Automoottorix

Automatisoin Nginxin asennuksen Ansiblella.

Loin roolin nginxille main.yml osoitteeseen... 
_tuttua kauraa jo_

Sisältö:

````
- apt:
    name: nginx
    state: present
    update_cache: true

- service:
    name: nginx
    state: started
    enabled: true
````
Lisäsin site.yml:ään:
````
- hosts: all
  become: true
  roles:
    - nginx
````
Ajoin ansible playbookin
JA 
Testasin seuraavasti...
``
curl http://localhost
``
_Hyvältä näyttää_
## Apache Ansiblella

Tässä tehtävässä automatisoin Apache2:n asennuksen Ansiblella käyttäen package-file-service -mallia.

Loin roolin apache2, jossa:

asennetaan Apache (apt)
kopioidaan konfiguraatiotiedosto (copy)
luodaan linkki (file)
restartataan palvelu tarvittaessa (handler)

Käytin omaa HTML-sivua kotihakemistossa:
````
~/publicsite/index.html
````
ja annoin sille oikeudet:
````
chmod ugo+x ~
chmod ugo+x ~/publicsite
chmod ugo+r ~/publicsite/index.html
````
Konfiguraatio ohjasi Apachen käyttämään tätä kansiota.

Ajoin playbookin
JA
Testasin seuraavasti...(_taas_)
````
curl http://localhost
````
Sivu toimi ja oli muokattavissa tavallisena käyttäjänä.

Ajoin playbookin uudelleen ja muutoksia ei tullut → idempotenssi toteutui.
