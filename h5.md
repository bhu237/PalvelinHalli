## x) Tiivistelmät

### What is Git?

- Git on hajautettu versionhallintajärjestelmä, joka tallentaa projektin muutokset ja historian

Oma huomio: Korvaamaton työkalu minkäänlaisessa kehityksessä, on se ohjelmistojen tai videopelien.

---

## Gitin komentoja

Komennot:

- `git add --all`
Lisää kaikki muutokset staging-alueelle

- `git commit`
Tallentaa muutokset versionhallintaan

- `git pull`
Hakee muutokset "varastosta", meidän esimerkissä oli github

- `git push`
Lähettää muutokset (meidän tapauksessa) GitHubiin

## b) Dolly

Kloonasin repon SSH-yhteydellä:

```bash
git clone git@github.com:bhu237/sunshine-repo.git
cd sunshine-repo
```
Lisäsin README.md-tiedostoon tekstin: 

```bash
echo "Hei hei mitä kuuluu?" >> README.md
```

Tallensin muutokset:

```bash
git add --all
git commit -m "päivitetty README"
git pull
git push
```

Muutokset näkyivät GitHubin web-käyttöliittymässä.

---

## c) Doh!

Tein muutoksen ilman commitointia:

```bash
echo "No kukkuluuruu" >> README.md
git diff
```
_Siis nyt unohdetaan commit, oh no!_

Poistin muutokset:

```bash
git reset --hard
```
Tämä palautti tiedostot viimeisimpään committiin ja poisti muutokset _pysyvästi_.

## d) Tukki

Tarkastelin commit historiaa:

```bash
git log
```
Komento `git log` kertoi minulle tarinaa että muutos kohdassa oli tehty paikallisesti, muttei oltu puskettu vielä GitHubiin.

Tarkastelin muutoksia: 

```bash
git diff
```

Seuraavaksi kiinnitin huomioni käyttäjätietoihin, kaikki siellä oli 100% oikein.

## e) Gitanbile

Lisäsin Ansible-kansion Git-versionhallintaan:

```bash
cd ~/ansible
git init
git add --all
git commit -m "ensimmäinen ansible-versio"
```

Tein muutoksen Ansible-rooliin ja tarkistin sen:

```bash
git status
git diff
```

Ajoin Ansible-playbookin:
_Tuttua kauraa jo_

````bash
ansible-playbook -i hosts.ini site.yml --ask-become-pass
````

Tallensin muutoksen:

````bash
git add --all
git commit -m "päivitetty ansible-tehtävää"
````
Tarkistin historian:

```bash
git log --oneline
```
Git ilmoitti lopuksi "working tree clean", mikä tarkoitti että kaikki muutokset oli tallennettu onnistuneesti.
